# StudentStay

### Simplifying the student housing search experience

StudentStay is a UI/UX design project exploring how the process of finding student accommodation can be made simpler, faster, and easier to navigate.

## Project Overview

Finding student housing can involve comparing multiple listings, prices, locations, amenities, and rental requirements across different platforms.

StudentStay explores a more focused experience designed around the needs of students searching for accommodation.

## Problem

Students often need to consider several factors when looking for housing, including:

* Monthly rent
* Distance from campus
* Room type
* Amenities
* Transportation
* Availability
* Rental requirements

The goal of this project is to create a more streamlined way for students to discover and compare housing options.

## Goal

Design a user-friendly housing search experience that allows students to:

* Search for accommodation
* Filter properties based on their needs
* View important property information
* Compare options
* Save properties
* Request a viewing
