# StudentStay Prototype

## Overview

The StudentStay prototype demonstrates the main user journey for finding and evaluating student accommodation.

The prototype focuses on making it easy for students to search for properties, apply filters, review property details, save listings, compare options, and request a viewing.

## Main User Flow

The primary flow is:

**Home → Search Results → Filters → Property Details → Contact Landlord → Confirmation**

Users can also:

**Home → Saved Properties → Compare Properties**

## Prototype Screens

The prototype includes the following screens:

1. Home
2. Search Results
3. Filters
4. Property Details
5. Saved Properties
6. Compare Properties
7. Contact Landlord
8. Viewing Request Confirmation

## Key Interactions

- Search for housing by location
- Browse available properties
- Filter properties by price, property type, bedrooms, bathrooms, and amenities
- View detailed property information
- Save properties
- Compare multiple properties
- Contact a landlord
- Request a property viewing
- Receive confirmation after submitting a request

## Design Goal

The goal of the prototype is to demonstrate a simple and intuitive housing search experience that helps students 
move from discovering properties to requesting a viewing with minimal effort.
